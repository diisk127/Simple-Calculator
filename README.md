1. วัตถุประสงค์ของโปรแกรม เพื่อพัฒนาโปรแกรมเครื่องคิดเลข (Calculator) โดยมีความสามารถในการคำนวณพื้นฐาน ได้แก่
 • การบวก (Addition)
 • การลบ (Subtraction)
 • การคูณ (Multiplication)
 • การหาร (Division) พร้อมตรวจสอบการหารด้วย 0


2. ขอบเขตการทำงาน
 • โปรแกรมต้องมีเมนูแสดงตัวเลือกให้ผู้ใช้เลือกการทำงาน (1–5)
 • โปรแกรมสามารถวนลูปให้ใช้งานต่อเนื่องได้จนกว่าผู้ใช้เลือกออกจากโปรแกรม (Exit)
 • ผลลัพธ์การคำนวณต้องถูกต้องและแสดงผลด้วยทศนิยม 2 ตำแหน่ง
 • มีการป้องกันกรณีหารด้วย 0


3. การออกแบบฟังก์ชัน
 • add(a, b) → ส่งค่าผลบวกของ a และ b
 • subtract(a, b) → ส่งค่าผลลบของ a และ b
 • multiply(a, b) → ส่งค่าผลคูณของ a และ b
 • divide(a, b) → ส่งค่าผลหารของ a และ b หาก b = 0 ให้คืนค่าข้อความ "Cannot divide by zero"


4. โครงสร้างโปรแกรม 
 4.1 โปรแกรมเริ่มต้นและแสดงเมนูดังนี้
   • Add Function
   • Subtract Function
   • Multiply Function
   • Divide Function
   • Exit
 4.2 ผู้ใช้เลือกหมายเลขเมนู
   • หากเลือกหมายเลขไม่ถูกต้อง โปรแกรมจะแจ้ง 
      "Please try again."
 4.3 หากเลือกเมนู 1 - 4 โปรแกรมจะรับค่าตัวเลข 2 ค่า   แล้วนำไปคำนวณด้วยฟังก์ชันที่กำหนด
 4.4 โปรแกรมแสดงผลลัพธ์ออกทางหน้าจอ
 4.5 หากผู้ใช้เลือกหมายเลข 5 โปรแกรมจะแสดง "End of the program..." และสิ้นสุดการทำงาน
